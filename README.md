# Business-Performance-Tool
A responsive, interactive BI dashboard that visualizes company KPIs, trends, and detailed business data. Built with HTML, CSS, JavaScript, and Chart.js, it uses a JSON data file (Pula currency) and supports dynamic filtering.

Features

· KPI Cards – Total Revenue, Expenses, Profit, Revenue vs Target
· Charts – Revenue trend (line), Expenses by department (bar), Revenue contribution (pie)
· Data Table – Sortable/searchable record list
· Filters – Department, region, month range
· Fully responsive – Works on desktop, tablet, mobile

🛠️ Technologies

· HTML5, CSS3, Bootstrap 5
· JavaScript (ES6)
· Chart.js
· JSON data storage
